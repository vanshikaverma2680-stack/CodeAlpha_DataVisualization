# The Mood Map of Music 🎵

## Overview

The Mood Map of Music is a data visualization project that explores audio characteristics of Spotify tracks and investigates how they relate to track popularity.

Using Python, Pandas, Matplotlib, and Seaborn, the project transforms track-level data into visual insights about musical characteristics, mood zones, and genre differences.

## Objectives

* Explore the distribution of track popularity.
* Create a mood map using energy and valence.
* Compare musical characteristics across selected genres.
* Examine relationships between audio features and popularity.
* Communicate findings through clear visualizations.

## Tools and Technologies

* Python
* Google Colab
* Pandas and NumPy
* Matplotlib and Seaborn

## Dataset

The analysis uses a publicly available Spotify tracks dataset.

Source: https://github.com/sai-chaitanya-reddy/spotify-tracks-dataset

The dataset contains track metadata and audio characteristics. Results depend on the dataset version and the records included in the analysis.

## Visualizations

1. Track popularity distribution
2. The Mood Map of Music
3. Average popularity across mood zones
4. Audio-feature correlation heatmap
5. Genre characteristics heatmap
6. Mean versus median genre popularity
7. Energy and popularity by valence group

## Methodology

The project includes data inspection, missing-value checks, duplicate checks, preparation of numerical features, exploratory visualizations, group comparisons, and correlation analysis.

## Key Findings

Findings are based on the actual outputs generated by the notebook. The final version will report the observed mood-zone distribution, genre comparisons, and audio-feature relationships.

## Limitations

The analysis describes the available dataset rather than all music or listeners. Popularity scores are not direct measures of musical quality, and correlations do not establish causation.
